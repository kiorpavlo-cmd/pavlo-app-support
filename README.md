# Pavlo Kior App Support

Static GitHub Pages site with support, privacy, and applications pages in English, Russian, Ukrainian, Lithuanian, Polish, German, and Spanish. The applications page lists Fat Alien and SeatCore.

The support form sends the visitor’s email, selected app, optional name, and message through FormSubmit to `kiorpavlo@gmail.com`. The visitor can reply directly because their email is used as the Reply-To address. FormSubmit requires a one-time confirmation email before it forwards submissions.

The support form does not send passwords or payment information. The Privacy page identifies FormSubmit and its stated 30-day submission retention period.
